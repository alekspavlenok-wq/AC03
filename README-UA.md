# Кастомне ядро Folia 26.3 — AC03

Це перенесення кастомного ядра на офіційну гілку Folia `ver/26.3.x`. Ця лінія позначена як alpha/experimental, тож перед оновленням основного сервера перевір її на копії світу й плагінів. Після відкриття світу в 26.3 не плануй відкат на старішу версію без окремої перевіреної резервної копії.

## Залізо та запуск

За скриншотом ПК має Xeon E5-2660 v4 (14 фізичних ядер / 28 логічних процесорів), 32 ГБ RAM і GT 730. Стартовий BAT передає JVM усі 28 логічних процесорів. Ліміт heap автоматично визначається за вільною RAM під час запуску: до 28 ГБ, із запасом щонайменше 3 ГБ для Windows, native-пам'яті JVM, плагінів і кешу файлів. Значення `-Xmx` є верхньою межею, а не обсягом, який Java одразу займає.

Профіль Paper/Folia залишає `12` потоків регіонального тікання, автоматичну кількість потоків генерації/завантаження чанків та `3` потоки chunk I/O. Для 14 фізичних ядер це агресивний стартовий профіль, але він не гарантує 250 гравців: результат залежить від відстані між гравцями, генерації чанків, плагінів, сутностей і швидкості одного тіку. Попередньо згенеруй світ, а потім тюнь кількість потоків за MSPT/TPS і профілем Spark.

GT 730 не може прискорити Minecraft-серверні тики: сервер не рендерить кадри. Графічні обчислення не можна просто перемкнути на відеокарту; штучно завантажувати її стороннім навантаженням знизило б продуктивність і не додало б гравцям TPS.

## Перенесення та збірка

Збірка використовує JDK 25 і завантажує залежності/вихідні дані Mojang та Paperweight з інтернету:

```powershell
./gradlew.bat applyAllPatches
./gradlew.bat :folia-server:createPaperclipJar
```

Готовий Paperclip JAR має з'явитися в `folia-server/build/libs`. У manifest задано бренд `AC03`; це незмінна назва в F3 для всіх наступних збірок.

Для запуску скопіюй JAR, `ops/start-server-memory-balanced.bat` і `ops/get-safe-heap.ps1` у нову папку сервера, потім запусти BAT. У новій папці спочатку запусти JAR один раз, прийми EULA лише якщо погоджуєшся з нею, а потім злий фрагменти з `ops/config/` у згенеровані конфіги. Не підміняй повні конфігураційні файли цими фрагментами. Для міграції світу збережи окрему резервну копію та перевір плагіни на копії.
